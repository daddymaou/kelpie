# @kelpie/vue-stub

The documented Vue API surface for Kelpie. No implementation is shipped yet — this package exists so the adapter's shape can be agreed on and reviewed before it is built. If you need the current documented surface, see the docs site; the design is the `useSync` / `useQuery` / `useMutation` shape shared with the React and Svelte adapters.

Why a stub: Kelpie only ships adapters that are actually tested. Publishing this interface first lets the API be critiqued without a half-maintained implementation.
